Interactive personal portfolio showcasing my work in **Artificial Intelligence, Deep Learning, Computer Vision, NLP, and Sales KPI Analytics**, powered by a custom **Cloudflare Workers AI Assistant**.

---

## ✨ Key Features

- 🤖 **Custom AI Portfolio Assistant:** Serverless backend built on **Cloudflare Workers** integrating multi-model routing (**Gemma 3 & Gemini**) with a bilingual (Arabic/English) Smart Intent Router fallback.
- 🎙️ **Voice & Text Interaction:** Supports bilingual queries (Arabic, English, and Code-Switching) with zero API key exposure.
- ⚡ **Automated CI/CD Deployment:** Deployed automatically via **GitHub Actions** to GitHub Pages on every push to `main`.
- 🎨 **Responsive Modern UI:** Clean, dark-themed engineering aesthetic built with semantic HTML5, CSS3, and vanilla JavaScript.
